    What would you like to know?

    Ask about Ward 5 or anything the City publishes as open data: for casework, briefings or council meetings. The assistant finds the right dataset, runs the numbers, draws charts and maps, and can save the data to this computer.

    Add the office's Claude API key in Settings to start asking. The dashboard works without it.

    Enter to ask. Shift and Enter for a new line. Answers come from the City's open data and show their sources.
